### *UI/UX Design: The "Undistracted Samadhi" Human-AI Interaction Model*

**Objective:** To design a frontend interface that rejects the "infinite scroll / dopamine loop" (ACQ) and instead fosters "continuous pure mindfulness" (AIE / 淨念相繼). The UI must visually represent the **Honesty Ledger** and the **Residual ($R \\\\neq \\\\emptyset$)**.

### 🎨 1. Core Design Principles
* **The Breathing Rhythm (呼吸感):** The interface pulses gently, mimicking the inhale (human intent) and exhale (AI response). It discourages frantic, rapid-fire prompting.
* **The Transparency of the Ledger (账本透明):** Every AI output is accompanied by its "epistemic metadata" (confidence, sources, residual).
* **The Graceful Void (无所得之留白):** When the AI reaches its limits, it does not hallucinate. It presents a beautiful, structured "Void" that invites human wisdom.

### 🔄 3. The Interaction Flow (The Loop of 淨念相繼)
1. **Inhale (Human Intent):** The user types in the *Breathing Input Field*. The UI visually "gathers" the text, applying the Six-Sense Protocol in the background.
2. **Restriction (RIM):** The AI processes the prompt. The *Honesty Ledger Overlay* updates in real-time, showing the user that the AI's "senses" are restricted and aligned.
3. **Exhale (Pure Emission):** The AI outputs the response in *Verified Blocks*. It does not guess; it states what it knows and explicitly marks the *Residual (R)*.
4. **The Pause (Samadhi):** The interface pauses. It does not auto-generate follow-up suggestions (which cause cognitive scattering). It waits for the human Conductor to review the Residual and provide the next deliberate input.
